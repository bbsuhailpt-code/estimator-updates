# Estimator updates

Public download point for the Estimator desktop app.

- **installers/** holds the Windows installers. Download the newest one for a first install.
- **latest.json** tells installed copies which version is newest; they update themselves from it. Updates are signed; only files signed with the Estimator key are accepted.
- **calendar.json** holds the moon-based dates (Ramadan, Eid, Diwali, Holi, Onam, Islamic New Year) used for the seasonal icons. Edit a date here when it is officially announced; installed copies pick it up automatically.

No project data, drawings or BOQs are ever stored here.
